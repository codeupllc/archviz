# Claude Code

Follow **[AGENTS.md](./AGENTS.md)** as the source of truth for contributing to Archviz.

In short:

1. Pick an open item on [Archviz AWS coverage](https://github.com/orgs/codeupllc/projects/1) (`P0` / `good first issue` preferred).
2. For AWS work, read [`docs/aws-coverage.md`](docs/aws-coverage.md) and follow [`.cursor/skills/add-aws-resource/SKILL.md`](.cursor/skills/add-aws-resource/SKILL.md).
3. One issue → one PR with `Fixes #<n>`; update coverage in the same PR; no drive-by refactors.
4. For UI-visible Studio changes, attach a **screenshot or short video** of the component in action (see AGENTS.md).

Also see [CONTRIBUTING.md](CONTRIBUTING.md).
